# Contributing to agentpack

Thanks for your interest in contributing!

## Getting Started

1. Fork and clone the repo
2. Install Rust (edition 2021+)
3. Run `cargo test` to verify everything works

## Development

```bash
cargo build          # Debug build
cargo test           # Run tests
cargo fmt            # Format code
cargo clippy         # Lint
```

## Pull Requests

- Fork the repo and create a branch from `dev`
- Keep PRs focused — one feature or fix per PR
- Add tests for new functionality
- Run `cargo fmt` and `cargo clippy` before submitting
- Write a clear PR description explaining what and why

## Reporting Issues

Use the [issue templates](https://github.com/OlegHQ/agentpack/issues/new/choose) for bug reports and feature requests.
