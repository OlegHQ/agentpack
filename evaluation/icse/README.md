# Offline ICSE contribution fixtures

Run `python3 evaluation/icse/run.py --binary /absolute/path/to/agentpack` from any directory. Requires Python 3 and the built agentpack CLI, no model key, native coding agent or network acquisition. Assertions check the real CLI's exits, contract outcomes, portable IDs and all fixture-owned file content/mode/link state. Output is produced from that run; no stored results are presented as measurements.

`clean.json` requires no planned checkout configuration write. `unknown.json` requires native observed skill presence and intentionally has no receipt. The same clean requirement with Cursor strict planning produces a violation. The source identity equality control uses two relocated checkouts and one external definition. The runner also checks an authored inherited user setting, a mismatched named skill, and an incomplete receipt claiming complete coverage. Their lock hash remains unchanged, demonstrating the limits of a lock-only control. These are synthetic correctness checks, not comparative tool or usability measurements. Opt-in restored-pack checks with two real CLI adapters are documented in `docs/src/guides/icse-evaluation.md`.
